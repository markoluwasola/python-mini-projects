**Python Mini Projects**



Two small console-based Python programs built while learning core programming concepts: control flow, loops, input validation, and error handling.



**Projects**



1\. **ATM Simulator**

Simulates basic ATM functionality — login, balance check, deposit, and withdrawal with PIN verification.



**Concepts practiced**: while loops, nested conditionals, input validation with try/except



Run it:

```bash

python TheATMSimulator.py

```



2\. **Library Fine Calculator**

Calculates late-return fines for library books based on days late and whether the book is a reference book.



**Concepts practiced**: nested conditionals, loop-based input validation, tiered pricing logic



Run it:

```bash

python TheLibraryFineCalaculator.py

```
